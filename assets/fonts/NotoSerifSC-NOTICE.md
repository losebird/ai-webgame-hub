# Noto Serif SC（即玩自托管子集）

- 字体：Noto Serif SC，SIL Open Font License 1.1，原文见同目录 `NotoSerifSC-OFL.txt`
- 上游：https://github.com/google/fonts/tree/main/ofl/notoserifsc （可变字体实例化为 500/600/700 后再按站点用字子集）
- 文件：`NotoSerifSC-{500,600,700}.woff2`，仅含本站 HTML/JS/CSS 与游戏中英标题简介中出现的字符，不是完整字库
- 未改字形轮廓。新的用户稿件若用到子集外汉字，会回退到系统宋体（Songti SC / STSong）
